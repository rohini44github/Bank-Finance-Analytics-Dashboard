# Bank-Finance-Analytics-Dashboard

🚀 Power BI Finance Analytics Dashboard | End-to-End Business Intelligence Project

I recently built an interactive Finance Analytics Dashboard in Power BI to help management monitor financial transactions, customer behavior, operational fees, taxes, and business performance across multiple dimensions.

🔹 Project Highlights

✅ Designed and developed a 2-page interactive dashboard from raw CSV data to actionable business insights.

✅ Built a robust data model (Star Schema) with optimized relationships for faster report performance.

✅ Performed data cleaning and transformation using Power Query, ensuring high-quality and analysis-ready data.

✅ Created dynamic DAX measures for:

Total Transaction Amount
Total Transactions
Average Transaction Value
Total Fees
Total Tax
Year-over-Year (YoY) Growth
Dynamic Metric Selection

✅ Developed interactive visualizations for:

Monthly Transaction Trends
Transaction Success vs Failed Analysis
Customer Segment Contribution
State-wise Financial Performance
Transaction Type Profitability Matrix
Gender-based Transaction Analysis

✅ Implemented advanced Power BI features:

Dynamic Slicers
Drill-through Report
KPI Cards
Conditional Formatting
Dynamic Titles
Bookmarks & Navigation Buttons
Custom Sidebar UI
📊 Business Impact Delivered

✔ Enabled stakeholders to monitor ₹135M+ transaction volume from a centralized dashboard.

✔ Reduced manual Excel-based reporting effort by approximately 70% through report automation.

✔ Improved decision-making speed by nearly 60% with real-time KPI tracking and interactive filtering.

✔ Helped identify high-value customer segments and top-performing states, supporting targeted business strategies.

✔ Simplified transaction monitoring by providing instant visibility into Success, Failed, and Pending transactions.

✔ Enhanced operational efficiency by consolidating multiple business reports into a single self-service BI solution.

✔ Improved analytical productivity through dynamic measure switching and drill-down capabilities.
